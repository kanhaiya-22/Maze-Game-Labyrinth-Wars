# 🧩 Maze Escape: A* Pathfinder vs. AI Opponent

**Maze Escape** is a Python game built using **Pygame**, where both a player bot and an AI opponent navigate a randomly generated maze using the **A\*** pathfinding algorithm. The player's goal is to reach the maze exit before being caught by the AI.

> 🎮 [Play Live on Trinket](https://trinket.io/pygame/9c38c66de3a2?outputOnly=true)

---

## 📌 Features

- 🔁 **Random Maze Generation** with optional loops
- 🧠 **A\*** algorithm for both player and AI pathfinding
- 🎨 **Color-coded entities**:
  - 🟩 Player Bot (Green)
  - 🟥 AI Opponent (Red)
  - 🟦 Exit (Blue)
- 🐢 Slowed AI movement for challenge balance
- 🛠️ Easy to customize, beginner-friendly code
